# GitHub Pages 上传说明

本文件夹可以直接上传到 GitHub 仓库根目录。

## 建议操作
1. 打开 `adult-happy-party` 仓库。
2. 点击 **Add file → Upload files**。
3. 将本文件夹内的全部文件和 `themes` 文件夹一起拖入上传区域。
4. Commit changes。
5. 打开 **Settings → Pages**，确认部署来源为 `main` 分支 `/ (root)`。
6. 等待 GitHub Pages 部署完成。

## 入口
- `index.html`：邀请入口
- `admin.html`：专属邀请链接生成器
- `01.html`：审批仪式
- `02.html`：澳门娱乐黑卡
- `03.html`：机密批复
- `04.html`：能量核心
- `05.html`：专属治疗方案

`themes/01.html`–`themes/05.html` 是旧链接兼容跳转页，请一起上传。
